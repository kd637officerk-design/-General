1. Upload everything in this folder to your GitHub repo (AETERNA-VITRIX), keeping the .github folder.
2. Open the Actions tab > "Build APK" > wait ~5 min > download the AETERNA-VITRIX-apk artifact (app-debug.apk) and install it.
3. First run: allow Music/Audio access, then in the app menu choose "Allow All files access" (needed to browse folders, edit and delete files).
